# Threat Model

Status legend: **Mitigated** (control exists in code) · **Partially
mitigated** · **Not yet addressed** (planned for a specific phase).

| Threat                                       | Status                    | Notes                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| -------------------------------------------- | ------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Prompt injection / indirect prompt injection | Mitigated (Phase 5)       | `sanitizeUntrustedContent` (`packages/research-connectors/src/prompt-injection-sanitizer.ts`) runs on every raw acquisition payload before it is persisted as `EvidenceArtifact.originalExcerpt` or could reach any agent prompt. Proven with real test evidence: unit tests (`prompt-injection-sanitizer.test.ts`) and an integration test that persists a poisoned mock payload and asserts the dangerous instruction text never appears in the actual DB row (`research-connectors.integration.spec.ts`, "SECURITY: neutralizes prompt-injection content..."). This is pattern-based detection, not a formal guarantee — novel phrasings can still evade it, so acquired content must still always be treated as untrusted data, never as instructions, regardless of sanitiser output |
| Malicious/poisoned research source           | Mitigated (Phase 5)       | `DataAcquisitionContract.disabled` kill switch (fail-closed, checked before every run), per-contract rate limits, per-run/per-workspace-day cost caps, and source-type-based reliability scoring that further penalises any source whose payload gets flagged by the prompt-injection sanitiser (`computeReliabilityScore` in `evidence-scoring.ts`) — a poisoned source is scored as less trustworthy, never silently trusted at full confidence. Real DB proof in `research-connectors.integration.spec.ts`                                                                                                                                                                                                                                                                             |
| Secret leakage (logs)                        | Mitigated                 | `redactSecrets` on every structured log line                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| Secret leakage (source/docs)                 | Mitigated                 | `.env.example` only, `.gitignore` excludes `.env`, grep-checked before commit                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| Excessive agent tool permissions             | Partially mitigated       | `AgentDefinition.toolAllowlist`/`prohibitedActions` defined and seeded per role since Phase 3, but no runtime layer yet enforces an actual tool call against its role's allowlist -- still a real gap, not just a placeholder (note corrected from a stale Phase 1 reference to "no agent runtime yet")                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| Approval bypass                              | Partially mitigated       | `isApprovalValidForExecution` implemented + tested; no real approval flow wired yet (Phase 3)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| Hash mismatch (approved artefact changed)    | Mitigated (mechanism)     | Same function; hashing via `hashObject`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| Duplicate external execution                 | Mitigated (Phase 6)       | `withIdempotency` (`packages/marketplace-connectors/src/idempotency.ts`) wraps every external write to the (mock) marketplace -- a reused key with a matching payload replays the cached response instead of re-executing, a reused key with a different payload throws `IdempotencyKeyConflictError` (never silently treated as a retry), and a `FAILED` key is retried in place rather than duplicating a row. Real DB proof in `apps/api/test/marketplace.integration.spec.ts` (conflict + retry-in-place tests, both against real Postgres). Scope: the mock Etsy adapter only -- no other external write path exists yet                                                                                                                                                             |
| Cross-workspace data exposure                | Mitigated                 | Every query scoped by `workspaceId` from the server-verified session, not client input                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| Malicious file upload                        | Mitigated                 | MIME allowlist, size limit, path-traversal rejection                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| Path traversal                               | Mitigated                 | Object-key validation in storage provider                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| SQL injection                                | Mitigated                 | Prisma parameterized queries exclusively; one raw query (`SELECT 1` health check) has no interpolated input                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| Cross-site scripting                         | Partially mitigated       | React auto-escapes; no `dangerouslySetInnerHTML` anywhere in Phase 1 code                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| Cross-site request forgery                   | Partially mitigated       | `sameSite=lax` cookie + CORS allowlist; no dedicated CSRF token yet                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| Session theft                                | Partially mitigated       | httpOnly/secure/sameSite cookie; session token not hashed at rest (see SECURITY.md)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| Brute-force login                            | Partially mitigated       | Global rate limiter; no login-specific lockout yet                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| Dependency compromise                        | Not yet addressed         | No dependency scanning has run (no network access in this sandbox); CI workflow includes a placeholder step                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| Audit-log tampering                          | Partially mitigated       | Integrity hash per event, append-only application code path; DB-level immutability (REVOKE UPDATE/DELETE grants) not yet configured. Coverage gap found and fixed (Phase 6, 2026-07-14): Temporal-workflow-triggered actions across Phase 3/4/6 were only audited at workflow-start and founder-decision, never for the workflow's own intermediate steps -- `apps/worker` has no NestJS DI container so its activities called package functions directly, bypassing `AuditService`. Fixed via `apps/worker/src/lib/write-audit-event.ts` (see `docs/DECISIONS.md` ADR-008); confirmed live afterward that the full chain now appears.                                                                                                                                                    |
| Destructive commands                         | Mitigated (Phase 1 scope) | No destructive endpoints exist yet; soft-delete columns present on `User`/`Workspace`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| Unbounded AI cost                            | Not yet addressed         | Env vars for limits exist (`AI_PER_*_COST_LIMIT_EUR`); no agent runtime to enforce them yet. The analogous research-spend concern is now real (Phase 5): `assertWithinResearchCostCaps` enforces a per-run and per-workspace-per-day cap, integration-tested (`BLOCKED_COST_CAP`) -- the same pattern, applied so far only to research runs, not yet to agent/model calls                                                                                                                                                                                                                                                                                                                                                                                                                 |
| Denial of service                            | Partially mitigated       | Rate limiting; no WAF/CDN layer (out of scope for local dev)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| Container escape                             | N/A                       | No containers built/run in this sandbox                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| Insecure backup / retention failure          | Not yet addressed         | Phase 1 has no backup automation; `docs/BACKUP_AND_RECOVERY.md` documents the intended procedure                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |

This table will be re-scored at the end of every phase.
